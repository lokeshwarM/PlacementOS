# Functional Requirements

## Student Features

- Instant placement alerts.
- Automatic eligibility checking.
- Shortlist detection.
- Original email access.
- Deadline reminders.
- Mark application as Done.
- Stop reminders after completion.

## Admin Features

- Monitor email ingestion.
- Reprocess failed emails.
- View notification logs.

## Supported Attachments

- Excel
- PDF
- Word

## Student Profile

- Registration Number
- NeoPAT ID
- Name
- Branch
- Batch
- CGPA
- Phone Number

## Non-Functional Requirements

- No duplicate notifications.
- Support thousands of users.
- Fast processing.
- Transparent decisions.
