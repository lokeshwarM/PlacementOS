# PlacementOS Vision

## Purpose

PlacementOS is an AI-assisted placement workflow platform designed to eliminate manual checking of placement emails, eligibility criteria, shortlist Excel sheets, and deadlines.

Instead of every student repeatedly opening Gmail and searching attachments, the system processes each CDC email once and delivers personalized notifications.

## Problem

Current workflow:

- Open Gmail.
- Read eligibility.
- Open Excel.
- Search Registration Number.
- Repeat.

This wastes time and causes missed opportunities.

## Solution

PlacementOS automatically:

- Detects placement emails.
- Extracts eligibility.
- Searches shortlist documents.
- Notifies eligible students.
- Tracks reminders.

## Guiding Principle

Parse once.

Personalize thousands of times.
